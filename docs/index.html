為什麼需要全字庫 Web Font？
Windows 預設「標楷體」與「新細明體」僅覆蓋常用 Big5 範圍，在 CJK Extension B（第二字面難字）與 第十五字面造字區（PUA 戶政專用字） 會直接顯示空白或豆腐塊（□）。全字庫 Web Font CDN 將全字庫龐大的八萬多漢字切分為小於 30KB 的微型分片，瀏覽器只下載當前頁面用到的字，載入迅速且完全補齊難字！
