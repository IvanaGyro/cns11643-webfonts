📌 為什麼需要全字庫 Web Font？

Windows 預設「標楷體」與「新細明體」僅涵蓋常用 Big5 範圍，在 CJK Extension B（第二字面難字）與 第十五字面造字區（PUA 戶政專用字） 會直接顯示空白或豆腐塊（□）。

💡 第三方開源解決方案：本專案依 SIL OFL 1.1 授權將全字庫八萬多漢字切分為微型分片（多數小於 30KB），瀏覽器只在遇到難字時透過 jsDelivr CDN 按需下載對應切片，兼具極速載入與完整補齊罕用字！
